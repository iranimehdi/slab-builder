# slab-builder

`build_slab.py` builds metal surface slabs and finite cluster models for DFT
adsorption studies (e.g. corrosion-inhibitor adsorption on steel) with the
[Atomic Simulation Environment (ASE)](https://wiki.fysik.dtu.dk/ase/).

It is the refined, general-purpose version of the short script that generated
the Fe surface model used in
*Synthesis and Characterization of Hexamethylenediamine–Oleic Acid Amide
Complexes with Hydrogen Bromide and Phosphoric Acid as Corrosion Inhibitors*.
The original script (`examples/genslab2_original.py`) is reproduced exactly by
`build_slab.py --legacy`. The model used in that paper is therefore the bcc **Fe(112)** surface
(50 atoms, two planes, 5×5), as explained in the note below.

## Features

* element, crystal structure (bcc / fcc / hcp / sc / diamond) and lattice
  constants from the command line, with sensible defaults from ASE's reference
  data (Fe defaults to the bcc lattice constant *a* = 2.83 Å used in the paper);
* arbitrary Miller indices, number of atomic planes, vacuum thickness and
  lateral repetition (supercell size);
* Miller indices applied to the **conventional cubic cell** by default, so that
  `(1 1 0)` means the literature Fe(110) plane (see the important note below);
* optional constraints: fix the *N* bottom planes (`--fix-bottom N`) or all
  metal atoms (`--fix-all`, rigid substrate as in the paper); atoms are tagged
  by plane index (1 = bottom);
* output in any ASE-supported format (`xyz`/`extxyz`, `cif`, `vasp`/POSCAR,
  `pdb`, `xsf`, `json`, `traj`, …), several at once;
* optional ORCA `%geom Constraints` block for the fixed atoms (`--orca`);
* a geometry report (planes, interlayer spacing, area per surface atom) that
  **identifies which crystallographic plane was actually built** and warns if
  it is not the one requested (`--check` turns the warning into an error).

## Installation

```bash
pip install ase numpy          # ASE ≥ 3.22 (tested with 3.29), Python ≥ 3.8
git clone https://github.com/slab-builder
cd slab-builder
python build_slab.py --help
```

## Usage

```bash
# Fe(110), 2 atomic planes, 5x5 supercell, 20 Å vacuum  (defaults)
python build_slab.py

# Cu(111), 4 planes, 4x4, bottom two planes fixed, POSCAR + extended XYZ + ORCA constraints
python build_slab.py -e Cu -s fcc --miller 1 1 1 -l 4 -r 4 4 --fix-bottom 2 -f vasp extxyz --orca

# Fe(112) (open, corrugated surface), 3 planes, 3x3, all Fe fixed, CIF
python build_slab.py --miller 1 1 2 -l 3 -r 3 3 --fix-all -f cif

# Reproduce the file generated by the original script (Fe_110_2layer_large.xyz)
python build_slab.py --legacy
```

All options: `python build_slab.py --help`.

| option | meaning | default |
|---|---|---|
| `-e, --element` | chemical symbol | `Fe` |
| `-s, --structure` | `bcc`, `fcc`, `hcp`, `sc`, `diamond` | ASE reference structure |
| `-a, --lattice-constant` | *a* in Å | ASE reference value (2.83 Å for Fe) |
| `-c, --c` | *c* for hcp (Å) | ideal *c/a* |
| `-m, --miller H K L` | Miller indices (conventional cell) | `1 1 0` |
| `-l, --layers` | number of atomic planes | `2` |
| `-v, --vacuum` | vacuum on each side (Å) | `20` |
| `-r, --repeat NX NY` | lateral repetition | `5 5` |
| `--primitive` | apply (hkl) to the primitive cell (legacy behaviour) | off |
| `--fix-bottom N` / `--fix-all` | FixAtoms constraints | none |
| `-f, --format …` | one or more output formats | `xyz` (extended XYZ) |
| `-o, --output` | output file name | auto, e.g. `Fe_110_2L_5x5.xyz` |
| `--orca` | write ORCA `%geom Constraints` block | off |
| `--check` | fail if the built plane ≠ requested (hkl) | off |
| `--periodic`, `--center`, `--view`, `-q` | periodic in z / center slab / open ASE GUI / quiet | off |

## Important note: primitive vs. conventional cell (what the original script built)

`ase.build.surface(bulk, (h, k, l), …)` interprets the Miller indices **with
respect to the cell object it is given**. `ase.build.bulk('Fe', 'bcc', a=a)`
returns the *one-atom primitive* rhombohedral cell of bcc iron, not the
two-atom cubic cell. In the primitive basis, (1 1 0) is the reciprocal-lattice
vector **b**₁ + **b**₂, which in conventional cubic indices is the **(1 1 2)**
plane (equivalently (2 1 1)).

Consequently, the original script

```python
fe_bulk = bulk('Fe', 'bcc', a=2.83)
slab = surface(fe_bulk, (1, 1, 0), layers=2, vacuum=20.0).repeat((5, 5, 1))
```

produces a slab with an interlayer spacing of 1.155 Å (= *a*/√6, the (112)
spacing) and 9.81 Å² per surface atom, **not** the Fe(110) surface
(spacing *a*/√2 = 2.001 Å, 5.66 Å² per atom, the most densely packed bcc
plane). `build_slab.py` therefore uses `bulk(..., cubic=True)` by default and
reports the plane it actually built. Use `--primitive` (or `--legacy`) only to
reproduce the old behaviour, and `--check` to make the script fail if the
geometry does not match the requested plane.

| command | plane built | d-spacing | atoms (2 planes, 5×5) |
|---|---|---|---|
| `--legacy` / `--primitive --miller 1 1 0` | Fe(112) | 1.155 Å | 50 |
| `--miller 1 1 0` (default, conventional) | Fe(110) | 2.001 Å | 100 |
| `--miller 1 1 2` (conventional) | Fe(112) | 1.155 Å | 100 |
